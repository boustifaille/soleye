# Soleye

(There is a french version of the [README](README.fr.md))

## Concept

Make an app that say if a sunset is going to be good-looking or not

## Development

Make sure you have nodejs and npm installed on your machine

Install dependancies

```sh
npm install
```

Run in development mode

```sh
npm run dev
```

Open app url in browser [http://localhost:5173]()
